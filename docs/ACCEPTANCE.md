## 图标自动分类 v2（Chrome 实机待验收）

- 混排 20 个以上真实 favicon，覆盖整块实心、圆角应用、透明镂空、小尺寸和自定义上传；检查默认自动分类与手动实心铺满 / 镂空 / 文字选项，刷新后手动选择优先。
- 特别检查知乎、哔哩哔哩等圆角应用图标是否被正确铺满，四角透明不应单独造成留白。原图自带的白色边框仍属于图片内容。
- 算法用 createImageBitmap 解码，在 32×32 画布上只取上、下、左、右边缘中点的 2×2 区域；四处平均 alpha 都严格大于 200 才是 filled，否则为 glyph。
- 检查 icon-cache 条目含 kind 与 v: 2；把旧条目版本改成 1，刷新后应从缓存 Blob 重新分类，不沿用旧 kind；分类缓存不进入数据备份。
- 小于 32px（任一边）的图标回退文字；解码、网络或缓存读写失败不阻止页面操作。确认未新增权限，本地图标不请求远程资源。
- 带半透明阴影、边缘中点有细缝的图标可能误判，由手动选项兜底；检查手动选项不会被自动结果覆盖。

本机浏览器预览已验证 24 个随包真实 favicon 均完成解码分类，知乎与哔哩哔哩均为 filled 并铺满；Chrome 扩展实机的权限、持久化及交互验收仍需按上列清单执行。

## 多标签、缓存与分组切换

- 20+ 标签在黄金重心、对称居中、显示/隐藏名称和窄窗中，网格左右边界与搜索行（包含右侧圆形按钮）保持一致；不同尺寸标签不越过右边界。
- 图标首次获取时生成 kind/v，回到已经浏览的分组保留原图标 DOM 和 Blob URL，不重复读取像素或图片解码；旧 v 仍需重新分类，失败后允许重试。
- 编辑、删除、改变尺寸、拖动排序、跨组移动、备份导入和外部数据变化后，相关组视图更新；删除分组后清理该组视图缓存。
- 书签区限高并内部滚动，overscroll-behavior: contain，页面不滚动。网格底部保留约半行线索，无粗滚动条；检查短窗口与抽屉布局。
- 起点就在边缘的触控板手势累计 120px 切组；中途才到边缘的剩余惯性不切组。鼠标在边缘单格不切，400ms 内连续两格切组。
- 切换后冷却 500ms，且必须静止超过 150ms 才识别新手势；首组向上、末组向下不切组、不提示，只回弹。
- 累计越界时位移不超过 24px，边缘低对比显示“继续滚动切换到「分组名」”，未达阈值则回弹。减少动态效果时关闭位移与淡入。
- 滚轮只滚动网格或侧栏，不再切换分组；点击侧栏或按全屏 ↑ / ↓ 切换分组（输入搜索框、设置面板、菜单、弹窗打开时不接管，不首尾循环）。
- 连续切组回归：光标固定，滚动至少标签组及空组；容器高度稳定，下一次有效边缘手势无需移动光标。

Node 已覆盖纯手势状态机及模拟 DOM 的滚动优先、提示回弹、旁路切换、节流。真实设备 delta 分布、浏览器原生滚动/contain、半行裁切、触控板惯性与动画质感、系统减少动态效果和窄窗抽屉仍待 Chrome 实机验收；本次未运行浏览器验证。


## 水平版心预设（居中 / 黄金）

沿用 `data-layout=center/golden` 和设置菜单原选项。桌面共用 `.workspace`，宽度 `min(61.8vw, 1200px)`，内侧栏 145px、列间距 38px、主列 1fr；时钟、搜索行、网格在同一主列，搜索行含右侧按钮。黄金只修改外部左余量为剩余空间的 0.382；禁止各组件单独 margin 补偿。<768px 仍沿用现有抽屉和左右内边距。

| 视口宽 | W | 居中：左 / 右 | 黄金：左 / 右 |

| 1440 | 892.8 | 273.6 / 273.6 | 209.0 / 338.2 |
| 1920 | 1186.6 | 366.7 / 366.7 | 280.1 / 453.3 |
| 2560 | 1200 | 680 / 680 | 519.5 / 840.5 |
| 3440 | 1200 | 1120 / 1120 | 855.7 / 1384.3 |

注意：1440 行与公式存在算术差异，1440×0.618=889.92，而非892.8。按公式正确值为 W=889.92、居中275.04/275.04、黄金210.13/339.95。本次实现遵循公式；其他三行与公式一致。

- 使用 DevTools 对 `.clock`、`.search-row`、`#grid` 读取 getBoundingClientRect，左缘严格相等；搜索行与网格右缘严格相等。

- 1440、1920、2560 两预设各一张截图、实测值及环境边界见 [水平版心验收记录](layout/README.md)。本次已用60标签与空组完成浏览器几何测量，390px抽屉也已检查。
