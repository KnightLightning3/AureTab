# 验收与后续事项

## 自动化

`npm test` 验证备份结构、版本、非法 URL / 图片类型、合并 ID 冲突、覆盖、排序、搜索编码和图搜大小限制。

## Chrome 实机验收（待逐项执行）

- 在 `chrome://extensions` 加载根目录，确认只申请 storage / favicon。
- 空分组添加首个图标；编辑、删除、四档尺寸（1×1 / 2×1 / 1×2 / 2×2）；请求图标并选择带背景 / 镂空 / 文字；自定义图标与回退文字；刷新后保留。
- 混合 100+ 大小图标，拖拽组内排序与跨组移动；同时开两个新标签检查数据刷新。
- 在 390px / 767px / 768px / 1920px / 3840px 窗口检查溢出、dense 排列、抽屉和版心。
- 页面不同目标右键，检查内容、Esc / 点击外部 / 滚动 / resize 关闭及四角不溢出；输入框原生菜单仍可用。
- 大尺寸壁纸导入后核对最长边不超过 1920px、JPEG；检查刷新、清除、模糊和遮罩。
- 导出带图片备份，移除已有内容再覆盖导入，核对标题、URL、顺序、尺寸、设置、图标和壁纸。合并应新建导入分组、保留当前设置和壁纸。
- 导入损坏 JSON、不支持版本、脚本 URL、重复 ID、伪造图片，确认有提示且已有数据不丢失。
- 三引擎文本搜索、引擎记忆、极简开关及记忆；地址栏焦点实测，不添加额外强制兜底。
- 三引擎图片上传需先完成 IMAGE_SEARCH.md；当前仅验收降级、10MB 限制、非图片提示、CORS / 断网提示、复制拒绝后保存图片。
- 真实扩展页面测量骨架与网格可交互时间，记录设备和冷 / 热启动；100ms 尚非验证结论。
