## 公式与实测

版心宽 `min(61.8vw, 1200px)`；居中余量均分；黄金左余量乘 `0.382`。以下为浏览器 DOM 几何测量，四舍五入到 0.01px。

| 视口宽 | W | 居中左 / 右 | 黄金左 / 右 |
|---|---|---|---|
| 1440 | 889.91 | 275.04 / 275.05 | 210.13 / 339.96 |
| 1920 | 1186.55 | 366.72 / 366.73 | 280.17 / 453.27 |
| 2560 | 1200 | 680 / 680 | 519.52 / 840.48 |
| 3440 | 1200 | 1120 / 1120 | 855.68 / 1384.32 |

用户原表 1440px 行的 `W=892.8` 与 `61.8vw` 不一致。按公式应为 `889.92px`，左右余量以本表为准；未用额外像素补偿凑原表。

以上桌面宽度的时钟 / 搜索行 / 网格左缘 x 严格相等，搜索行（含右侧圆形按钮） / 网格右缘 x 严格相等；1440、1920、2560 的空分组也通过同样测量。两种预设的主列相对容器左侧均为 183px（145px 侧栏 + 38px 列间距），内部相对位置不变。

1440px 下修改前后时钟 top=162、搜索行 top=261.8359375、网格 top=433.3359375，保留原黄金预设的纵向基线。桌面居中预设不再附加原来的 70px 顶距，使两预设切换仅移动水平方向；宽屏原有纵向媒体查询仍保留。390px 下确认容器宽 100%、左右内边距 22px，抽屉初始隐藏，点选分组后关闭，窄窗规则未调整。
