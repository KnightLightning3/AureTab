隐私政策

最后更新：2026 年 10 月 21 日 · 生效日期：2026 年 10 月 21 日

摘要

  • AureTab 不要求注册账号，不收集姓名、邮箱、电话等身份信息。
  • 开发者不运营用于接收用户数据的服务器，扩展不提供云同步。
  • 站点、分组、设置、壁纸和上传的图标保存在你的浏览器本地。
  • 搜索关键词会发送给你选择的搜索引擎；获取站点图标时会请求 Google 或 DuckDuckGo；读取远程图片链接时会访问对应网站。
  • 不出售用户数据，不用于广告、用户画像或信用评估。

1. 适用范围与维护者

AureTab（简称“本扩展”）是一款由个人开发者 KL 维护的 Chrome / Edge 新标签页扩展。本政策说明本扩展如何处理你的信息，适用于本扩展的 Chrome 与 Edge 版本以及本页面。

本扩展替换浏览器的新标签页，提供搜索、分组站点、自定义外观、本地壁纸和本地数据备份功能。它不是浏览器本身，也不会更改你的默认搜索引擎设置。

2. 保存在本地的数据

以下数据仅保存在你当前设备的浏览器中，不会由开发者接收：

数据保存位置用途
站点名称、网址、所属分组、排序和图标设置 chrome.storage.local 中的 appData 在新标签页网格中显示你的站点
主题、布局、搜索引擎、壁纸选择等偏好 chrome.storage.local 中的 devicePrefs 恢复外观与行为设置
你上传的壁纸、自定义图标及其缩略图 扩展的 IndexedDB 数据库（easy-tab-assets） 显示壁纸和图标，并供备份使用
你主动导出的备份文件 由你选择保存位置的 JSON 文件 迁移或恢复你的配置

扩展没有账号系统，也没有开发者服务器。开发者无法查看、读取或恢复上述本地数据。

3. 会离开设备的数据

为了显示网页内容或完成你主动发起的操作，扩展会让浏览器向第三方服务发出请求。这些请求会包含目标网址以及常规网络信息（例如 IP 地址、User-Agent、请求时间），具体取决于相应服务的实现。

3.1 站点图标

对于没有随安装包提供、也没有本地缓存的图标，扩展会尝试 Chrome 提供的 favicon 接口，以及 Google 和 DuckDuckGo 的图标服务。使用远程图标服务时，站点域名会作为请求参数发送给 Google favicon 服务或 DuckDuckGo 图标服务。在新标签页显示图标或打开图标选择器预览时，都可能触发这类请求。

扩展本身不读取、不保存你的 IP 地址或设备定位；但上述服务的运营方会像处理普通网页请求一样收到这些信息，并可能据此推断大致地区。相关处理受其各自的隐私政策约束。

3.2 搜索

当你提交搜索时，扩展会把关键词拼接到你所选搜索引擎的网址并在新标签页打开。当前可选 Google、百度、Bing 和搜狗。关键词及常规网络信息会发送给对应搜索引擎，由其按照自身隐私政策处理。

3.3 图片链接与以图搜图

  • 当你拖入或粘贴图片链接时，扩展会从该网址直接下载图片用于后续操作；该网址所在网站会收到你的 IP 地址等常规请求信息。
  • 使用以图搜图时，扩展会把图片写入系统剪贴板，并打开你选择的搜索引擎的官方识图页面。扩展当前不会自动上传图片；你在第三方页面粘贴并上传后，图片由该第三方处理。扩展不读取剪贴板中的其他内容。

3.4 打开站点

点击站点卡片会打开对应网址，这属于你主动发起的正常浏览行为，相应网站会收到常规网络请求信息。

3.5 扩展不使用的服务

本扩展不包含广告 SDK、统计分析、崩溃上报、远程配置或开发者运营的同步服务，也不会为上述目的向第三方传输数据。

4. 共享、出售与用途限制

开发者不出售、出租或交易用户数据，也不会将用户数据用于广告投放、用户画像、信用评估或贷款目的。

除第 3 节所述、为完成扩展功能而由浏览器发出的请求外，扩展不会向开发者或任何其他方传输你的数据。

本扩展对用户数据的处理遵守 Chrome Web Store 用户数据政策，包括其中的 Limited Use（有限使用）要求：仅为实现扩展单一用途所必需的目的使用数据，不将数据用于无关目的，也不将其转移给不相关的第三方。

5. 保留期限与删除方式

本地数据会一直保留，直到你主动删除或卸载扩展。

  • 删除单个项目：在扩展界面删除站点、分组、自定义图标或壁纸。
  • 清除全部数据：打开 chrome://extensions（Edge 为 edge://extensions），移除 AureTab。浏览器会删除该扩展的本地存储和 IndexedDB 数据。
  • 删除备份：导出的 JSON 文件由你保管，请自行删除。
删除图标或壁纸后，扩展会尝试回收不再被引用的图片数据。浏览器底层存储的物理清除时间由 Chrome 或 Edge 管理，扩展无法保证立即擦除。已经发送给第三方服务的请求记录不由开发者控制，需按照相应服务的政策处理。

6. 扩展权限说明

权限用途
storage在本机保存站点、分组、偏好和备份所需的数据。
favicon通过浏览器提供的 favicon 接口读取你添加站点的图标，用于新标签页网格展示。

本扩展不申请访问所有网站的权限，不读取你的标签页列表、浏览历史、书签、下载记录、密码或剪贴板内容。

7. 儿童隐私

本扩展不会有意收集儿童的个人信息。由于扩展没有账号系统，也不向开发者传输数据，开发者不会持有儿童的个人数据。

8. 安全

你的配置保存在浏览器提供的本地存储中，开发者无法远程访问。请妥善保管导出的备份文件，因为其中可能包含你的站点网址、名称和图片。若你在共用设备上使用本扩展，请在离开前清除扩展数据或使用独立的浏览器配置文件。

9. 政策更新

如果扩展的数据处理方式发生变化，开发者会更新本页面并修改页面顶部的日期。涉及重大变化时，还会在扩展的商店说明或发布说明中提示。继续使用更新后的扩展，即表示你接受更新后的政策。
