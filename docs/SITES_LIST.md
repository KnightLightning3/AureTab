# 站点清单与分类选择器

## 文件位置

data/sites.json 是图标编辑弹窗“从常用站点选择”的唯一数据源。它是纯文本 JSON，不含 Logo、图片、截图、base64 或远程资源地址。

## 数据结构

~~~json
{
  "schemaVersion": 1,
  "categories": [
    { "id": "dev", "name": "开发" }
  ],
  "sites": [
    { "name": "GitHub", "domain": "github.com", "aliases": ["git"], "cat": "dev", "icon": "github.com.png" }
  ]
}
~~~

- categories 当前 10 类：常用、新闻资讯、音乐视频、社交、购物、开发、设计、AI、学习办公、工具。
- 每个 category id 唯一；每个站点必须引用存在的 cat。
- 每类 12–20 条，总数不超过 200；当前 162 条。
- domain 只写域名，不带协议、路径、端口、空格或查询参数；选中后统一拼成 https://<domain>/。
- aliases 是本地搜索用的中文别名、英文名、拼音或首字母；不引入拼音库。
- cat 只用于分类浏览，不展示给用户。

## 增删规则

1. 新增站点时补齐 name、domain、aliases、cat，并确认域名不重复。
2. 删除站点直接删除 sites 中的一行；无需改其他文件。
3. 每次修改后运行 npm test，确认分类数量、域名格式、每类 12–20 条、总数不超过 200。
4. 新增或修改域名前人工打开站点核对；不收录停运、广告、小众或不稳定站点。
5. 不自动联网更新清单；清单随扩展版本发布。

## 分类选择器行为

- 首次打开选择器时才动态加载选择器模块和 sites.json，加载后缓存在内存；图标文件随扩展本地发布。
- 左侧顶部固定“自定义图标”入口；它不来自 sites.json，点击后进入手动填写或自定义图片上传流程。
- 顶部搜索在同一份内存清单中匹配 name、aliases、domain，不区分大小写，前缀优先；防抖 150ms，最多 24 条。
- 搜索无结果时提示“未找到，可直接输入网址”；用户仍可手动输入网址。
- 图标从 assets/site-icons/<icon> 读取，icon 字段指向本地文件名；缺失或加载失败时显示站点名首字占位。
- 新增站点时同步下载本地图标并填写 icon 字段；选择器不请求远程 favicon，也不打开网页。
- 本地图标来自站点公开 favicon，部分站点只有 16 / 32px 源图；若显示偏软，替换对应本地文件，不恢复运行时抓取。

## 合规约束

- `data/sites.json` 只允许站点名称、域名、别名、分类和本地图标文件名，不得出现 base64、远程图片地址或内联 SVG。
- 站点图标是 `assets/site-icons/` 下单独随包发布的本地 favicon 文件，不写入清单；选择器与网格运行时都不再从远程抓取这些图标。
- 扩展名称、描述和界面文案不得出现第三方品牌名；站点清单中的站点名称是例外。
- 不增加 host_permissions，不接入在线图标搜索或第三方搜索接口。
- 下架某站点时同时删除 `data/sites.json` 中的行和 `assets/site-icons/` 中对应的图标文件，避免残留品牌资源。
- 清单和图标更新前人工核对域名有效性、图标来源与合规性；图标文件较多，当前只做了格式和引用完整性校验。
