# 站点清单与分类选择器

## 文件位置

data/sites.json 是图标编辑弹窗“从常用站点选择”的唯一数据源。它是纯文本 JSON，不含 Logo、图片、截图、base64 或远程资源地址。

## 数据结构

~~~json
{
  "schemaVersion": 1,
  "categories": [
    { "id": "dev", "name": "开发" }
  ],
  "sites": [
    { "name": "GitHub", "domain": "github.com", "aliases": ["git"], "cat": "dev", "icon": "github.com.png" }
  ]
}
~~~

- categories 当前 10 类：常用、新闻资讯、音乐视频、社交、购物、开发、设计、AI、学习办公、工具。
- 每个 category id 唯一；每个站点必须引用存在的 cat。
- 每类 12–24 条，总数不超过 200；当前 166 条。
- domain 只写域名，不带协议、路径、端口、空格或查询参数；选中后统一拼成 https://<domain>/。
- aliases 是本地搜索用的中文别名、英文名、拼音或首字母；不引入拼音库。同一别名不得对应两个站点；有歧义的短别名（如 tb / db / so / dd）应删除，而不是在搜索里排序猜测。
- cat 只用于分类浏览，不展示给用户。

## 增删规则

1. 新增站点时补齐 name、domain、aliases、cat，并确认域名不重复。
2. 删除站点直接删除 sites 中的一行；无需改其他文件。
3. 每次修改后运行 npm test，确认分类数量、域名格式、别名唯一性、每类 12–24 条、总数不超过 200。
4. 新增或修改域名前人工打开站点核对；不收录停运、广告、小众或不稳定站点。
5. 不自动联网更新清单；清单随扩展版本发布。

## 分类选择器行为

- 首次打开选择器时才动态加载选择器模块和 sites.json，加载后缓存在内存；图标文件随扩展本地发布。
- 左侧顶部固定“自定义图标”入口；它不来自 sites.json，点击后进入手动填写或自定义图片上传流程。
- 顶部搜索在同一份内存清单中匹配 name、aliases、domain，不区分大小写，前缀优先；防抖 150ms，最多 24 条。
- 搜索无结果时提示“未找到，可直接输入网址”；用户仍可手动输入网址。
- 图标从 assets/site-icons/<icon> 读取，icon 字段指向本地文件名（png / jpg / webp / ico / svg）；缺失或加载失败时显示站点名首字占位。精选 SVG 与 favicon 均随插件统一封装。
- 带横版文字标识的品牌额外填写 `iconWide`，指向同一目录下的横版 SVG；2×1 横向图标优先使用它，未填写时显示 icon 本身。
- 新增站点时同步准备本地图标并填写 icon 字段（品牌在 LobeHub 图标集中时复制对应 SVG）；选择器不请求远程 favicon，也不打开网页。
- 未替换的本地图标来自站点公开 favicon，不足32px的旧源图已转为文字占位；保留的部分32px图仍可能偏软，后续可替换对应本地文件，不恢复运行时抓取。

## 合规约束

- `data/sites.json` 只允许站点名称、域名、别名、分类和本地图标文件名（icon / iconWide），不得出现 base64、远程图片地址或内联 SVG。
- 站点图标是 `assets/site-icons/` 下单独随包发布的本地 favicon 文件，不写入清单；选择器与网格运行时都不再从远程抓取这些图标。
- 扩展名称、描述和界面文案不得出现第三方品牌名；站点清单中的站点名称是例外。
- 不增加 host_permissions，不接入在线图标搜索或第三方搜索接口。
- 下架某站点时同时删除 `data/sites.json` 中的行和 `assets/site-icons/` 中对应的图标文件，避免残留品牌资源。
- 清单和图标更新前人工核对域名有效性、图标来源与合规性；图标文件较多，已做格式、比例、哈希、引用完整性及精选联系表复核，未逐项核对各品牌最新外部条款。

## 本地版本选择与背景

编辑器将来源、显示样式和背景独立保存。来源仅显示白名单内经审查的经典主图与合格横版，另保留文字、自定义上传及主动远程请求。重复颜色或相似副本不再逐个列出。请求远程图标后仍可切回精选本地版本。

data/icon-variants.json 是精选索引，仅引用 assets/site-icons/ 文件名；通过 `npm run icons:refresh` 从 data/icon-selection.json 重建，无需原始图标库。新加素材先更新 data/icon-whitelist.json 并按 docs/ICON_CURATION.md 的流程审查。旧图标库路径和旧文件名通过兼容表映射到封装副本，运行时不会请求 Git 忽略目录。

已验证横版用于 2×1 横向尺寸；缺少精确横版时使用主图。显示样式仍可选自动、实心铺满、镂空；背景默认玻璃效果，可选含纯黑、纯白的固定色板，随备份保存。

市场仍为166站点，其中149站点有合格主图、32站点有横版；17个待补素材站点使用文字占位，不借用同公司其他产品 Logo。详细来源和待补清单见 docs/ICON_CURATION.md。
