# Lobe Icons 静态 SVG 素材

来自 https://github.com/lobehub/lobe-icons 的官方 npm 包 `@lobehub/icons-static-svg`，版本 1.95.1。

本目录保存包内全部 SVG 原始文件，未经修改。版本、下载地址和 SHA-512 完整性信息见 SOURCE.json；完整 MIT 许可及版权声明见 LICENSE。再分发时请一并保留。

文件名不带后缀的是单色图标；`-color`、`-text`、`-text-cn`、`-brand`、`-brand-color` 等后缀表示上游提供的不同变体，具体以实际文件为准。

使用示例：`<img src="assets/icons/lobe-icons/openai.svg" alt="OpenAI" width="24" height="24">`。
